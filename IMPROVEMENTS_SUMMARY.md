## 🚀 How to Use

### First Time?
1. Open `dashboard.html` in your browser
2. Click the theme toggle (🌙) for dark mode
3. Check out the new "Portfolio Analytics" tab
4. Star a stock to add it to your watchlist
5. Search for a company to find stocks quickly

### For Trading:
1. Use the search bar to find stocks
2. Click any stock to see detailed analysis
3. Check the price chart for trends
4. Read agent reasoning for decision support
5. Monitor your watchlist for price changes

### For Portfolio Management:
1. Go to "Portfolio Analytics" tab
2. Check your P&L percentage
3. Review individual positions
4. Monitor cash available
5. Adjust allocation if needed

## 📞 Support

### Common Issues

**Q: Dark mode won't toggle**
A: Refresh the page and try again. Your preference saves during the session.

**Q: Charts not showing**
A: Make sure you're using a modern browser. Charts require HTML5 Canvas.

**Q: Notifications not appearing**
A: Check if notifications are enabled (bell icon in header should be active).

**Q: Search not finding stocks**
A: Try searching by ticker (e.g., "RELIANCE") instead of full name.

**Q: Mobile layout broken**
A: Update your browser to the latest version for best experience.
