# 🚀 Dashboard Feature Guide - Quick Start

## What's New?

Your Antigravity Financial Intelligence dashboard has been completely redesigned with improved UI/UX and powerful new features!

## 🌓 Dark Mode

**Location**: Top-right corner (moon/sun icon)

- Click to toggle between light and dark themes
- Your preference persists during your session
- Optimized colors for both modes
- Better for late-night trading sessions

---

## 📊 Portfolio Analytics (NEW!)

**Location**: Fourth tab in header (💼 icon) or main navigation

### What you can see:
- **Total Portfolio Value**: Your entire portfolio in rupees
- **Available Cash**: Ready-to-deploy capital
- **Total P&L %**: Your portfolio's performance percentage
- **Active Positions**: Number of stocks you own

### Holdings Table:
- All your stock positions in detail
- Current price and shares held
- Average cost basis
- Current total value
- Profit/Loss in rupees and percentage
- Color-coded performance (green = positive, red = negative)

## ⭐ Watchlist Management

**Location**: Left sidebar under "My Watchlist"

### Features:
- Add stocks to your watchlist by clicking the star (⭐) icon
- See real-time price and change % for each stock
- Quick visual indicator of positive/negative moves
- Perfect for monitoring stocks you're interested in

### How to Use:
1. Click any stock's star icon to add to watchlist
2. View all watchlisted stocks in the left sidebar
3. Click the price to navigate to that stock
4. Remove by clicking the star again

## 📈 Price Charts

**Location**: Right panel under "Synthesis Orchestrator Verdict"

### Features:
- 5-day price history visualization
- Line chart with area fill
- Clear trend identification
- Updates with market simulations
- Responsive to screen size

### Interpretation:
- Blue line = stock price over time
- Area below = price movement range
- Points = daily price close

## 🎯 Search & Filter

**Location**: Below ticker ribbon (search bar)

### Features:
- Search by stock ticker (e.g., "RELIANCE", "TCS")
- Search by company name (e.g., "Reliance Industries")
- Real-time filtering of ticker ribbon
- Case-insensitive matching

### Quick Tips:
- Search as you type - results update instantly
- Ticker ribbon shows matching stocks
- Click any result to select that stock

## 📍 Price Alerts

**Location**: Data Pipeline Test section

### Pre-configured Alerts:
- TATAMOTORS: Alert if price goes above ₹650
- HDFCBANK: Alert if price goes below ₹1680

### Alert Types:
- **Above**: Trigger when price rises above target
- **Below**: Trigger when price falls below target
- **Active**: Enable/disable alerts anytime

### How It Works:
1. Alerts are checked on each market tick
2. Notifications appear in top-right when triggered
3. Check active alerts in the sidebar

## 📞 Support

### Common Questions:

**Q: How do I add a stock to my watchlist?**
A: Click the star (⭐) icon next to any stock name

**Q: Can I change the price alert threshold?**
A: Yes, pre-configured alerts are visible in the Data Pipeline Test section

**Q: What do the colors mean in the P&L column?**
A: Green = profit/positive return, Red = loss/negative return

**Q: Why is my chart not updating?**
A: Click "Simulate Market Tick" to update prices and charts

**Q: Is my data real?**
A: No, all data is clearly marked as SIMULATED for demo purposes

## 🎯 Key Metrics Explained

- **RSI (14)**: Ranges 0-100. Above 70 = overbought, Below 30 = oversold
- **P/E Ratio**: Price-to-Earnings. Lower = cheaper relative to profits
- **Confidence %**: How confident the system is in its recommendation
- **Suggested Allocation %**: Recommended portfolio percentage for this stock
- **HHI Index**: Portfolio concentration (0.24 = well diversified)
- **Forward Return**: Expected 30-day return from this analysis
